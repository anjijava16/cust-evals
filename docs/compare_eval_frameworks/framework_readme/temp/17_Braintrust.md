## Quick Overview

Braintrust is an **AI product evaluation platform** renowned for its **exceptional developer experience**. It provides automatic versioning, real-time evaluation, dataset management, and best-in-class CI/CD integration—all with a focus on making developers productive from day one.

```bash

pip install braintrust

pip install braintrust autoevals  # For pre-built evaluators
```

### Setup (3 Minutes)

```bash
export BRAINTRUST_API_KEY="your-api-key"

# Or in Python
import os
os.environ["BRAINTRUST_API_KEY"] = "your-api-key"
```

### Basic Evaluation Example (5 Minutes)

```python
from braintrust import Eval

# Define your model/system
def qa_model(input: dict) -> str:
    """Your Q&A model."""
    question = input["question"]
    # Your LLM logic here
    return f"Answer to: {question}"

# Define scorer
def accuracy_scorer(output: str, expected: dict) -> float:
    """Score the output."""
    expected_answer = expected["expected"]
    # Simple keyword match
    score = 1.0 if expected_answer.lower() in output.lower() else 0.0
    return score

# Run evaluation
eval_result = Eval(
    "My Q&A System",
    data=[
        {
            "input": {"question": "What is AI?"},
            "expected": {"expected": "Artificial Intelligence"}
        },
        {
            "input": {"question": "What is ML?"},
            "expected": {"expected": "Machine Learning"}
        }
    ],
    task=qa_model,
    scores=[accuracy_scorer]
)

print(f"✓ Evaluation completed!")
print(f"  View results at: https://www.braintrust.dev/")
```

### With Automatic Tracing

```python
from braintrust import traced

@traced
def retrieve_documents(query: str):
    """Automatically traced."""
    docs = ["Doc 1", "Doc 2", "Doc 3"]
    return docs

@traced
def generate_answer(query: str, docs: list):
    """Automatically traced."""
    answer = f"Answer based on {len(docs)} documents"
    return answer

@traced
def qa_pipeline(question: str):
    """Full pipeline traced."""
    docs = retrieve_documents(question)
    answer = generate_answer(question, docs)
    return answer

# Use normally - all traced automatically
result = qa_pipeline("What is AI?")
```

### 2. CI/CD Integration

**GitHub Actions:**
```yaml
# .github/workflows/evaluate.yml
name: Evaluate Model

on:
  pull_request:
    branches: [main]

jobs:
  evaluate:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v2

      - name: Set up Python
        uses: actions/setup-python@v2
        with:
          python-version: '3.10'

      - name: Install dependencies
        run: |
          pip install braintrust
          pip install -r requirements.txt

      - name: Run evaluation
        env:
          BRAINTRUST_API_KEY: ${{ secrets.BRAINTRUST_API_KEY }}
        run: python evaluate.py

      - name: Comment PR
        uses: braintrust-dev/braintrust-action@v1
        with:
          github-token: ${{ secrets.GITHUB_TOKEN }}
```
