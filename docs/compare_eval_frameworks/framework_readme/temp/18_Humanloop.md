# Humanloop: Human-in-the-Loop Evaluation & Prompt Management

**Type**: Cloud Platform | **License**: Commercial (Freemium) | **Year**: 2022

---

## Quick Overview

Humanloop is a **human-in-the-loop evaluation platform** with exceptional focus on **human feedback collection**, **prompt management**, and **A/B testing**. It bridges the gap between automated evaluation and human judgment, making it ideal for applications where human feedback is critical.

### At a Glance

| Aspect | Details |
|--------|---------|
| **Focus** | Human feedback + prompt management + A/B testing |
| **Setup Time** | 15-20 minutes |
| **Learning Curve** | Medium |
| **Dependencies** | Cloud platform |
| **Cost** | Free (limited) + Starter ($99) + Pro ($499) + Enterprise |
| **Best For** | Human feedback, prompt optimization, user-facing apps |

## Quick Start

### Installation

```bash
# Install Humanloop SDK
pip install humanloop

# Or with specific integrations
pip install humanloop openai
pip install humanloop anthropic
```

### Setup (5 Minutes)

```python
import os
from humanloop import Humanloop

# Get API key from https://app.humanloop.com/
os.environ["HUMANLOOP_API_KEY"] = "your-api-key"

# Initialize client
hl = Humanloop(api_key=os.getenv("HUMANLOOP_API_KEY"))

print("✓ Humanloop initialized")
```

### Basic Prompt Usage

```python
from humanloop import Humanloop

hl = Humanloop()

# Create a prompt (via API or UI)
# Then use it in code

# Generate with prompt
response = hl.chat(
    project="qa-assistant",
    messages=[
        {
            "role": "user",
            "content": "What is machine learning?"
        }
    ],
    model_config={
        "model": "gpt-4",
        "temperature": 0.7,
        "max_tokens": 150
    }
)

print(f"Response: {response.data[0].output}")
print("✓ Generation logged to Humanloop")
```

### Collecting User Feedback

```python
from humanloop import Humanloop

hl = Humanloop()

# Generate response
response = hl.chat(
    project="chatbot",
    messages=[{"role": "user", "content": "Hello!"}]
)

log_id = response.data[0].id

# User provides feedback (thumbs up/down)
hl.feedback(
    log_id=log_id,
    rating=1,  # 1 = positive, 0 = negative
    feedback_text="Great response, very helpful!"
)

print("✓ User feedback collected")
```

### A/B Testing Prompts


## Key Features Deep Dive

### 1. Human Feedback Collection

**Rating Systems:**
```python
from humanloop import Humanloop

hl = Humanloop()

# Generate response
response = hl.chat(
    project="assistant",
    messages=[{"role": "user", "content": "Explain quantum computing"}]
)

log_id = response.data[0].id

# Binary feedback (thumbs up/down)
hl.feedback(
    log_id=log_id,
    rating=1  # 1 = positive, 0 = negative
)

# Star rating (1-5)
hl.feedback(
    log_id=log_id,
    rating=4,  # 4 out of 5 stars
    feedback_text="Good explanation but could be simpler"
)

# Detailed feedback
hl.feedback(
    log_id=log_id,
    rating=1,
    feedback_text="Perfect! Exactly what I needed.",
    metadata={
        "user_id": "user_123",
        "session_id": "session_456",
        "context": "first_time_user"
    }
)
```

**Annotation Queues:**
- Create queues for manual review
- Assign to team members
- Track progress
- Inter-annotator agreement
- Quality assurance workflows

### 2. Prompt Management


### 4. Preference Ranking

**Pairwise Comparison:**

```python
    project="preference_ranking",

    responses=responses,
```

### 5. Dataset Management

**Create Evaluation Sets:**
```python
from humanloop import Humanloop

hl = Humanloop()

# Create dataset
dataset = hl.create_dataset(
    project="qa-assistant",
    name="golden_test_set",
    description="High-quality Q&A pairs"
)

# Add examples
examples = [
    {
        "input": "What is AI?",
        "expected_output": "Artificial Intelligence",
        "metadata": {"category": "definitions"}
    },
    {
        "input": "What is ML?",
        "expected_output": "Machine Learning",
        "metadata": {"category": "definitions"}
    }
]

for example in examples:
    hl.add_dataset_example(
        dataset_id=dataset.id,
        **example
    )

# Run evaluation on dataset
results = hl.evaluate_dataset(
    dataset_id=dataset.id,
    model_config={
        "model": "gpt-4",
        "temperature": 0.7
    }
)

print(f"Evaluation results: {results}")
```
